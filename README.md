# Yuliang Yan — Personal Academic Website

Built with [Hugo](https://gohugo.io/) and deployed automatically to GitHub Pages (`gh-pages`) via GitHub Actions.

## Local Development

```bash
hugo server -D
```

## Updating Content

- **Bio**: `content/_index.md`
- **Profile, Socials, Interests, Education**: `data/profile.yaml`
- **Publications**: `data/publications.yaml` (set `selected: true` to show on the homepage)
- **Experience**: `data/experience.yaml`
- **Academic Service**: `data/service.yaml`
- **CV PDF & Images**: `static/pdf/` and `static/img/`
